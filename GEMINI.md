# Development Commands

## Build
To perform a full production build including type checking:
```bash
npm run build
```

## Test
To run all tests once (non-watch mode):
```bash
npm test -- --run
```

## Lint
To check code style and linting rules:
```bash
npm run lint
```

To automatically fix linting issues and format code according to the project style:
```bash
npm run lint:fix
```
